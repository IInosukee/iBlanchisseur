# Script de Blanchisseur en RageUI
Pour le start ensure iBlanchisseur dans le serveur cfg

# Config simple
Tout se règle dans `Config.lua` : temps d'attente, taux de retour, montant minimum, nom/modèle/arme du PNJ, distance d'interaction et position.

Compatible ESX Legacy (export `getSharedObject`) et anciennes versions d'ESX (event `esx:getSharedObject`).
